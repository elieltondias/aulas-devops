# Aula de Quarta — Hello World

## Descrição
Projeto introdutório da Aula de Quarta para praticar os conceitos básicos de HTML e Git. Contém uma página simples que exibe a mensagem "Olá, Mundo!" no navegador.

## Estrutura
- `HelloWorld.html` — página HTML com a mensagem de boas-vindas.
- `README.md` — documentação do projeto.

## Como executar
1. Clone este repositório ou baixe os arquivos.
2. Abra o arquivo `HelloWorld.html` diretamente no navegador (duplo clique), ou
3. Com VS Code, use a extensão Live Server e clique em "Go Live".

## Tecnologias
- HTML5
- Markdown (documentação)
